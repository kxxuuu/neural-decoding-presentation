# Machine Learning for Neural Decoding

English presentation for ECE 590 by Boyi Zhao and Ke Xu.

Based on Glaser et al. (2020), *Machine Learning for Neural Decoding*, eNeuro.
https://doi.org/10.1523/ENEURO.0506-19.2020

## Viewing

Open `index.html` locally, or use the GitHub Pages site. The 17-slide presentation includes embedded figures and speaker notes, and works offline.

- Arrow keys or Space: navigate
- F: fullscreen
- N: speaker notes
- O: contents
- Click a figure: enlarge

## Attribution

Paper figures are reproduced from Glaser et al. (2020), licensed under CC BY 4.0. Selected panels are cropped and rearranged; sources are identified in the presentation.
